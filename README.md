# codeAlpha_HangmanGame
A simple text-based Hangman game built with Python as a part of the CodeAlpha Python Programming Internship

## 🎮 Features

- Randomly selects a word from a predefined list
- Player guesses the word one letter at a time
- Maximum 6 incorrect guesses allowed
- Displays the progress of the hidden word
- Handles repeated and invalid guesses
- Shows win or game-over message

## 🛠️ Technologies Used

- Python
- Random module
- Loops
- Conditional statements
- Strings and Lists

## ▶️ How to Run

1. Clone this repository.
2. Open the project folder in VS Code or any Python IDE.
3. Run `hangman.py`.
4. Enter one letter at a time to play.
